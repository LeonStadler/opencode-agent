# Code Quality & Build

1. **No lint or build errors** — fix all reported issues before marking work complete.
2. **Do not resolve by removing code** — fix root causes; never delete functionality to work around errors.
3. **DRY** — extract shared logic; avoid repetition.
4. **Best practices** — follow established project conventions over personal preference.
5. **Maintainability** — use hooks, APIs, and components sensibly; keep the system extensible.
